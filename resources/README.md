# Resources

## 品牌源

`brand/universe-agent-studio.svg` 复制自同一所有者仓 `Singular/logo/singularity.svg`（commit `ef47cda7`）。用户于 2026-09-02 显式授权将 Singularity 标识用作 UniverseAgentStudio 应用图标。入仓时几何与颜色未改，仅将 `aria-label` 从 `UnitServer` 改为 `UniverseAgentStudio`。

全部平台图标由 `build/brand/generate-icons.mjs` 从这一份矢量源生成；≤48px 使用脚本内写死的粗线派生，浅底变体由主源反色生成，不引用 `singular-white.svg`。
