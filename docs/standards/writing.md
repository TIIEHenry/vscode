# 写作

语言、frontmatter、索引、链接和术语的写法以 [文档文体指南](../guides/doc-style-guide.md) 为正文。本页只补充文档系统的三条约定。目录角色见 [文档系统](../design/document-system.md)。

## 文件名不当状态

文件名用来从目录里认出主题。计划、决策和收件箱的状态写在正文状态行。文件名里不使用 `draft`、`final`、`latest`、`done` 或版本号充当这份文档的身份。

新建前运行：

```bash
python3 scripts/wiki/wiki.py check-new <路径> --root .
```

路径中不使用空格、`#`、`%` 或括号。决策文件名写主题，不使用全局顺序号。一次审查放在 `dev/reviews/<开始日期>-<主题>/`。目录名里的日期是这次审查开始的日期，开始之后不随进度改名。

## 新计划与决策用正文状态行

新建的计划、决策和收件箱条目，在一级标题下第一行写 `状态：…。`。取值，以及多人同时工作时怎样写负责人，见 [状态行](../../scripts/wiki/formats.md#计划决策记录和待处理项的状态行)。

已有文件的 frontmatter 保留。存量计划不批量补状态行。

## 同一主题一份当前正文

同一适用范围里，一个主题保留一份当前正文。其他页面用相对链接指向它。AI 工具生成的计划、报告和调研写入 `dev/`。
